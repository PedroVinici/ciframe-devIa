# [Título: decisão de introduzir persistência para sequências de acordes customizadas]


O projeto so não possuia uma feature que permitisse uma busca por sequencias customizadas montadas pelo usuário. Para viabilizar essa feature introduzimos a capaciade de persistir essas sequencias e permitir que sobrevivam entre reinicios da aplicação e que seja acessíveis para todos os usuários.
